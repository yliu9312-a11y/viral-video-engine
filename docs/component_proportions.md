# 1080×1920 竖屏组件比例规范

> 基于 TikTok/Instagram Reels 官方规范 + 实际爆款视频分析

## 画布与安全区

```
画布: 1080 × 1920 px (9:16)

安全区 (实际可用):
  上: 250px (平台 UI)
  下: 340px (CTA 按钮、分享栏)
  左: 60px (边距)
  右: 180px (点赞/评论/分享)

可用区域: 840 × 1330 px
可用面积占比: 54%
```

## 字号规范 (相对画布)

| 用途 | 字号 | 占画布宽度 | 实际物理高度* | 使用场景 |
|------|------|-----------|-------------|---------|
| Display | 96px | 8.9% | ~5.7mm | Hook 巨字、CTA 价格 (1视频≤2次) |
| Headline | 64px | 5.9% | ~3.8mm | 主标题、卖点 |
| Body | 40px | 3.7% | ~2.4mm | 字幕、说明 (99% 用这个) |
| Caption | 28px | 2.6% | ~1.7mm | 数据标注、品牌名 |

*基于 6.1 英寸手机 (424 PPI)

**关键比例关系:**
- Display ÷ Headline = 1.5x ✅
- Headline ÷ Body = 1.6x ✅
- Body ÷ Caption = 1.43x ≈ 1.5x ✅

## 间距规范 (8 倍数制)

| Token | 值 | 用途 |
|-------|-----|------|
| xs | 8px | 元素内小间距 |
| sm | 16px | 相关元素间距 |
| md | 24px | 组内间距 |
| lg | 32px | 区块间距 |
| xl | 48px | 大区块间距 |
| 2xl | 64px | 主要分隔 |
| 3xl | 96px | 画面分区 |

## 组件占画布比例上限

| 组件类型 | 最大宽度 | 最大高度 | 最大面积占比 |
|---------|---------|---------|------------|
| 全屏背景 | 100% | 100% | 100% |
| 主内容组件 | 80% | 50% | 40% |
| 浮层组件 | 60% | 40% | 24% |
| 标签/徽章 | 30% | 8% | 2.4% |
| 按钮 | 25% | 5% | 1.25% |

## 留白规则

- 组件上下间距: ≥ 32px (md)
- 组件左右间距: ≥ 24px (sm)
- 文字行间距: 1.3-1.5 倍字号
- 段落间距: ≥ 1.5 倍行间距
- 画面留白: 至少 30% 的画面是"空的"
